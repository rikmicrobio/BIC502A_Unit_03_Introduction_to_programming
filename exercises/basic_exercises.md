# BIC502A Unit III — Practice Exercises

Try these before looking at solutions.

## Part A — Basics

1. Create variables for a gene, organism and sequence.
2. Print the sequence length.
3. Print the first and last base.
4. Extract the first three bases.
5. Count G bases.

## Part B — Data structures

6. Create a list of five genes.
7. Add a sixth gene.
8. Remove one gene.
9. Create a dictionary containing gene name, length and organism.
10. Use a set to find unique bases.
11. Create a 3 × 3 nested list and access its centre.

## Part C — Conditions

12. Check whether a sequence is longer than 100 bases.
13. Categorize a sequence as short, medium or long.
14. Check whether GC content is above 50%.
15. Use `and` to check two conditions.

## Part D — Loops

16. Print every base in a DNA sequence.
17. Count A using a loop.
18. Print 1–20 using `range()`.
19. Use `break` to stop when G is found.
20. Use `continue` to skip A.
21. Print every value in a nested list.

## Part E — Functions

22. Write a function that returns sequence length.
23. Write a function that counts a specified base.
24. Write a function that calculates GC content.
25. Write a function that reverses a sequence.
26. Use a function inside a loop to analyze five sequences.
27. Write a function with a default argument.

## Part F — Integrated bioinformatics task

Create a dictionary containing at least four named DNA sequences.

Write functions to calculate:

- sequence length
- A count
- T count
- G count
- C count
- GC percentage

Use a loop to analyze every sequence and print a clear report.
